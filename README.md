# Kingsford Meal Planner

A weekly, repeating meal framework and an offline phone app for one uni student in Kingsford NSW. It works with a **$150/week grocery budget** plus **3 HelloFresh meals** a week, high protein and quick cooks.

The framework is **"Wednesday Shop, Sunday Box"**: shop on Wednesday when the specials start and cook 4 quick dinners Wed–Sat. HelloFresh arrives Sunday and covers Sun–Tue. Every dinner is cooked for two, and the second serving is tomorrow's lunch.
